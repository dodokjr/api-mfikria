Admin: Buat Master Token

Halaman ini khusus admin. Masukkan Admin Key dan nama untuk membuat token admin (tanpa batas waktu) lewat POST /v2/token/master. Master token dipakai pengguna untuk membuat access token di halaman Access Token.

Buat Master Token

Admin key tidak disimpan di browser dan dikosongkan setelah master token dibuat.

Teks bebas, maksimal 15 karakter. Dicatat bersama token di Google Sheet.
