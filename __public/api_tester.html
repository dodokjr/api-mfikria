Api Test Tools

Uji API dari localhost maupun host publik. Kirim request GET, POST, PUT, PATCH, DELETE dengan query, header, dan body (JSON, teks, form), lalu lihat respons lengkap beserta kode status dan header.

Host / Environment

Pilih server tujuan: localhost untuk development atau host publik. Di kolom URL cukup tulis path (misalnya /v2/anime), otomatis digabung dengan Base URL.

Cara mengaktifkan CORS di server lokal 
// Express (Node.js)
const cors = require('cors');
app.use(cors()); // izinkan semua origin saat development

// Tanpa library, kirim header ini di setiap respons:
// Access-Control-Allow-Origin: *
// Access-Control-Allow-Methods: GET, POST, PUT, PATCH, DELETE, OPTIONS
// Access-Control-Allow-Headers: Content-Type, Authorization
// Balas request OPTIONS (preflight) dengan status 204
