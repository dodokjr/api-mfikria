Getting Started

Semua endpoint memakai method yang tertera dan membalas JSON. Respons sukses berisi "status": "success", respons gagal berisi "status": "error" dan "message".

Base URL

  • https://api-mfikria.vercel.app/mfikria/v1Guest token, video, share/embed, dan akun
  • https://api-mfikria.vercel.app/v2/githubGitHub
  • https://api-mfikria.vercel.app/v2/animeAnime
  • https://api-mfikria.vercel.app/v3/lk21Movies & Series

Alur singkat

  1. Ambil guest token dengan POST /mfikria/v1/guest-token.
  2. Tempelkan ?query={Access_Token}&tgl={tanggal} pada endpoint yang butuh token (GitHub, video, share-info).
  3. Simpan token dan pakai ulang, jangan buat token baru di setiap request.

Endpoint publik tanpa guest token: /guest-token, /guest-view, /share, /embed, /s/{id}/stream, dan /s/{id}/view.

Guest Token

Token untuk pengunjung tanpa login. Setiap token tercatat di Google Sheet (tab GuestTokens).

  • POST /mfikria/v1/guest-tokenBuat guest token. Tanpa body dan tanpa header
  • GET /mfikria/v1/guest-viewJumlah guest yang pernah masuk (view), di-cache 30 detik

Contoh respons

{
  "status": "success",
  "message": "Guest token berhasil dibuat.",
  "data": {
    "userId": "G001",
    "Access_Token": "...",
    "pukul": "1535",
    "tanggal": "091026"
  }
}

Cara memakai token

Kirim sebagai query pada endpoint yang butuh guest token: ?query={Access_Token}&tgl={tanggal}, dengan nilai dari respons di atas.

Batasan

Maksimal 10 token per IP per jam (lebih dari itu dibalas 429) dan token berlaku 24 jam secara default. Token yang salah atau kedaluwarsa dibalas 401.

Contoh Kode

Ambil guest token, lalu pakai untuk mengambil 5 repository milik dodokjr.

JavaScript vanilla (di browser)

const API = 'https://api-mfikria.vercel.app';

async function getRepos() {
  // 1. ambil guest token
  const tokenRes = await fetch(`${API}/mfikria/v1/guest-token`, { method: 'POST' });
  const { Access_Token, tanggal } = (await tokenRes.json()).data;

  // 2. pakai token di endpoint GitHub
  const params = new URLSearchParams({ per_page: 5, query: Access_Token, tgl: tanggal });
  const res = await fetch(`${API}/v2/github/dodokjr/repos?${params}`);
  console.log(await res.json());
}

getRepos().catch(console.error);

React (function component + hooks)

import { useEffect, useState } from 'react';

const API = 'https://api-mfikria.vercel.app';

export default function Repos() {
  const [repos, setRepos] = useState([]);

  useEffect(() => {
    async function load() {
      const tokenRes = await fetch(`${API}/mfikria/v1/guest-token`, { method: 'POST' });
      const { Access_Token, tanggal } = (await tokenRes.json()).data;

      const params = new URLSearchParams({ per_page: 5, query: Access_Token, tgl: tanggal });
      const res = await fetch(`${API}/v2/github/dodokjr/repos?${params}`);
      const data = await res.json();
      setRepos(Array.isArray(data) ? data : []);
    }
    load().catch(console.error);
  }, []);

  return (
    <ul>
      {repos.map((r) => (
        <li key={r.id}>{r.name}</li>
      ))}
    </ul>
  );
}

Node.js 18 atau lebih baru (fetch sudah bawaan)

const API = 'https://api-mfikria.vercel.app';

async function main() {
  const tokenRes = await fetch(`${API}/mfikria/v1/guest-token`, { method: 'POST' });
  const { Access_Token, tanggal } = (await tokenRes.json()).data;

Go (hanya library standar)

package main

import (
	"encoding/json"
	"fmt"
	"log"
	"net/http"
	"net/url"
)

const api = "https://api-mfikria.vercel.app"

func main() {
	// 1. ambil guest token
	res, err := http.Post(api+"/mfikria/v1/guest-token", "application/json", nil)
	if err != nil {
		log.Fatal(err)
	}
	defer res.Body.Close()

	var tok struct {
		Data struct {
			AccessToken string `json:"Access_Token"`
			Tanggal     string `json:"tanggal"`
		} `json:"data"`
	}
	if err := json.NewDecoder(res.Body).Decode(&tok); err != nil {
		log.Fatal(err)
	}

	// 2. pakai token di endpoint GitHub
	q := url.Values{}
	q.Set("per_page", "5")
	q.Set("query", tok.Data.AccessToken)
	q.Set("tgl", tok.Data.Tanggal)

	res2, err := http.Get(api + "/v2/github/dodokjr/repos?" + q.Encode())
	if err != nil {
		log.Fatal(err)
	}
	defer res2.Body.Close()

	var repos []struct {
		Name string `json:"name"`
	}
	if err := json.NewDecoder(res2.Body).Decode(&repos); err != nil {
		log.Fatal(err)
	}
	for _, r := range repos {
		fmt.Println(r.Name)
	}
}

Java 11 atau lebih baru (java.net.http bawaan, tanpa library tambahan)

import java.net.URI;
import java.net.URLEncoder;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.nio.charset.StandardCharsets;
import java.util.regex.Matcher;
import java.util.regex.Pattern;

public class Main {
    static final String API = "https://api-mfikria.vercel.app";

    // Ambil nilai string dari JSON sederhana (tanpa library JSON)
    static String find(String json, String key) {
        Matcher m = Pattern.compile("\"" + key + "\"\\s*:\\s*\"([^\"]*)\"").matcher(json);
        if (!m.find()) throw new IllegalStateException("Field tidak ditemukan: " + key);
        return m.group(1);
    }

    public static void main(String[] args) throws Exception {
        HttpClient client = HttpClient.newHttpClient();

        // 1. ambil guest token
        HttpRequest tokenReq = HttpRequest.newBuilder()
                .uri(URI.create(API + "/mfikria/v1/guest-token"))
                .POST(HttpRequest.BodyPublishers.noBody())
                .build();
        String tokenBody = client.send(tokenReq, HttpResponse.BodyHandlers.ofString()).body();
        String token = find(tokenBody, "Access_Token");
        String tanggal = find(tokenBody, "tanggal");

        // 2. pakai token di endpoint GitHub
        String url = API + "/v2/github/dodokjr/repos?per_page=5"
                + "&query=" + URLEncoder.encode(token, StandardCharsets.UTF_8)
                + "&tgl=" + URLEncoder.encode(tanggal, StandardCharsets.UTF_8);

        HttpRequest reposReq = HttpRequest.newBuilder().uri(URI.create(url)).GET().build();
        HttpResponse<String> res = client.send(reposReq, HttpResponse.BodyHandlers.ofString());
        if (res.statusCode() != 200) {
            throw new RuntimeException("HTTP " + res.statusCode());
        }
        System.out.println(res.body());
    }
}

GitHub

Ganti {nama} dengan username GitHub dan {repo} dengan nama repository. Semua endpoint butuh guest token (?query=&tgl=) dan dibatasi 60 request per menit per IP.

  • GET /v2/github/{nama}Profil pengguna
  • GET /v2/github/{nama}/reposDaftar repository
  • GET /v2/github/{nama}/repos/{repo}Detail satu repository
  • GET /v2/github/{nama}/repos/{repo}/eventsAktivitas repository
  • GET /v2/github/{nama}/repos/{repo}/languagesBahasa pemrograman yang dipakai
  • GET /v2/github/l/limitSisa kuota GitHub API (limit, remaining, reset)

Parameter opsional

Untuk /repos dan /events: per_page (1–100) dan page (1–1000). Contoh: /v2/github/dodokjr/repos?per_page=5&page=1&query=...&tgl=...

Kode error

  • 400Username atau nama repo tidak valid
  • 401Guest token tidak ada atau tidak valid
  • 404User atau repository tidak ditemukan
  • 429Batas request tercapai (server atau GitHub)
  • 502Gagal mengambil data dari GitHub

Respons di-cache sekitar 60 detik, jadi data bisa terlambat sedikit dari GitHub.

Video

Semua endpoint butuh guest token (?query=&tgl=). {token} adalah videoToken (10 karakter) dari daftar video.

  • GET /mfikria/v1/videosDaftar video beserta views, tanggal upload, dan info share
  • GET /mfikria/v1/video/{token}Stream video (mendukung Range), pakai sebagai src elemen <video>
  • GET /mfikria/v1/video-info/{token}Info satu video: judul, ukuran, views, tanggal upload, share
  • POST /mfikria/v1/video-view/{token}Catat 1 view. Panggil sekali setelah video diputar beberapa detik

Catatan

/video-view membalas { views, counted }. Satu guest hanya dihitung sekali untuk setiap video, jadi counted bernilai false pada panggilan berikutnya.

Kode error

  • 401Guest token tidak valid
  • 404Video tidak ditemukan
  • 500Terjadi kesalahan di server

Share & Embed

{id} adalah shareId dari objek share pada daftar video (sama dengan videoToken). Endpoint ini publik, tanpa guest token, kecuali /share-info.

  • GET /mfikria/v1/share/{id}Link untuk dibagikan. Langsung diarahkan ke halaman nonton di situs
  • GET /mfikria/v1/embed/{id}Player polos untuk <iframe>
  • GET /mfikria/v1/share-info/{id}Link share, kode iframe, dan link media sosial satu video (butuh guest token)
  • GET /mfikria/v1/s/{id}/streamStream video bertanda tangan (?e=&s=), dipakai halaman embed
  • POST /mfikria/v1/s/{id}/viewCatat view dari halaman embed (?e=&s=)

Contoh embed

<iframe src="https://api-mfikria.vercel.app/mfikria/v1/embed/k4n8lSIppy" width="640" height="360" frameborder="0" allow="fullscreen; autoplay" allowfullscreen loading="lazy" title="Judul video"></iframe>

Bot media sosial (WhatsApp, Facebook, Telegram, dan lain-lain) tetap mendapat halaman dengan meta Open Graph supaya preview link muncul. Link stream bertanda tangan berlaku 6 jam.

Akun

Endpoint akun memakai header Authorization: Bearer {token akses} (token akses user atau admin). Body dikirim sebagai JSON.

  • POST /mfikria/v1/registerDaftar akun. Body: username, password, role (opsional), photoId (opsional)
  • POST /mfikria/v1/loginMasuk. Body: username, password
  • POST /mfikria/v1/logoutKeluar. Body: username, encryptedQueryToken
  • GET /mfikria/v1/photosDaftar foto di folder Google Drive
  • GET /mfikria/v1/photoProfile/{token}Foto profil dari token terenkripsi
  • GET /mfikria/v1/assets/photo/{photoId}?q={token}Foto profil dengan photoId dan token
  • GET /mfikria/v1/assets/session-photo/{photoId}?query={encryptedQueryToken}Validasi sesi, atau ambil foto. Dengan Accept: application/json hanya data verifikasi

Aturan

  • Username maksimal 50 karakter, password 6–128 karakter.
  • Akun admin hanya bisa dibuat dengan token akses admin.
  • Satu akun hanya bisa aktif di satu sesi. Login saat akun masih online dibalas 403.
  • Password disimpan sebagai hash (scrypt), bukan teks asli.

Contoh respons /login

{
  "status": "success",
  "message": "Login Berhasil sebagai USER",
  "dashboardData": {
    "profile": { "userId": "U001", "username": "...", "role": "user", "statusLogin": "true",
                 "terakhirLogin": { "tanggal": "...", "pukul": "..." } },
    "permissions": { "canUploadFile": false, "canModifyData": false, "accessLevel": "View Only (User)" },
    "sessionTokens": { "accessToken": "...", "encryptedQueryToken": "..." },
    "googleDrivePhoto": { "photoId": "...", "token": "..." }

Kode error

  • 400Data wajib tidak lengkap atau tidak valid
  • 403Token akses salah, username atau password salah, atau akun sedang online
  • 404Username tidak ditemukan (logout)
  • 500Terjadi kesalahan di server

Anime

Endpoint dasar /v2/anime langsung menampilkan halaman home. Masih dalam pengembangan.

  • /v2/animeHalaman home
  • /v2/anime/{query}Cari anime, contoh /v2/anime/naruto
  • /v2/anime/full/{id}Detail lengkap anime
  • /v2/anime/popularAnime populer (Top Anime)
  • /v2/anime/populer/page/{id}Anime populer per halaman
  • /v2/anime/character/{id}Karakter anime
  • /v2/anime/character/people/{id}Pengisi suara karakter

  • /v3/lk21/movies/d/{judul}Detail movie

  • /v3/lk21/series/populerSeries populer
  • /v3/lk21/series/d/{judul}Detail series
  • /v3/lk21/s/{judul}Cari movie atau series
