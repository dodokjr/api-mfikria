Getting Started

Semua endpoint memakai method yang tertera dan membalas JSON. Respons sukses berisi "status": "success", respons gagal berisi "status": "error" dan "message".

Endpoint /v2/anime/otaku, /v2/donghua/anichi, /v2/world, /v2/country, /v2/currencies, dan /v2/currency memakai Access Token yang dikirim lewat header Authorization: Bearer. Endpoint lain (GitHub, video, share-info) memakai guest token.

Buat Access Token

Langkah pertama: dapatkan token

Sebelum memakai endpoint apa pun yang butuh token (GitHub, video, share-info), kirim request POST ke URL berikut untuk mendapatkan guest token, lalu simpan token tersebut.

  • POST https://api-mfikria.vercel.app/mfikria/v1/guest-tokenTanpa body dan tanpa header
const res = await fetch('https://api-mfikria.vercel.app/mfikria/v1/guest-token', { method: 'POST' });
const { Access_Token, tanggal } = (await res.json()).data;

// simpan token supaya bisa dipakai ulang
localStorage.setItem('guest_token', Access_Token);
localStorage.setItem('guest_tgl', tanggal);

Simpan Access_Token dan tanggal dari respons (misalnya di localStorage, variabel environment, atau database). Token berlaku 24 jam dan dibatasi 10 token per IP per jam, jadi pakai ulang token yang sudah tersimpan dan jangan buat token baru di setiap request. Buat token baru hanya jika belum punya atau sudah kedaluwarsa (dibalas 401).

Base URL

  • https://api-mfikria.vercel.app/mfikria/v1Guest token, video, share/embed, dan akun
  • https://api-mfikria.vercel.app/v2/githubGitHub
  • https://api-mfikria.vercel.app/v2/animeAnime
  • https://api-mfikria.vercel.app/v2/tokenAccess token (buat dan cek status)
  • https://api-mfikria.vercel.app/v2/anime/otakuAnime Otakudesu (butuh access token)
  • https://api-mfikria.vercel.app/v2/donghua/anichiDonghua Anichin (butuh access token)
  • https://api-mfikria.vercel.app/v2/worldEkonomi dunia, semua negara (butuh access token)
  • https://api-mfikria.vercel.app/v2/countryCari satu negara, contoh /v2/country/ID (butuh access token)
  • https://api-mfikria.vercel.app/v2/currencyKurs dan daftar mata uang, termasuk /v2/currencies (butuh access token)

Alur singkat

  1. Kirim POST /mfikria/v1/guest-token untuk mendapatkan token, lalu simpan Access_Token dan tanggal.
  2. Tempelkan ?query={Access_Token}&tgl={tanggal} pada endpoint yang butuh token (GitHub, video, share-info).
  3. Pakai ulang token yang tersimpan sampai kedaluwarsa, jangan buat token baru di setiap request.
  4. Untuk /v2/anime/otaku dan /v2/donghua/anichi, buat Access Token di halaman Access Token, lalu kirim di header Authorization: Bearer.

Endpoint publik tanpa token: /guest-token, /guest-view, /share, /embed, /s/{id}/stream, /s/{id}/view, serta POST /v2/token dan GET /v2/token/status.

Access Token

Token untuk memanggil /v2/anime/otaku, /v2/donghua/anichi, /v2/world, /v2/country, /v2/currencies, dan /v2/currency. Token berlaku 10 hari dan setiap token tercatat di Google Sheet (tab AccessTokens). Cara termudah: buat lewat halaman Access Token.

Buat Access Token
  • POST /v2/tokenBuat access token. Body JSON { "name": "..." }, opsional (teks bebas maksimal 15 karakter, kosong = nama acak 15 karakter)
  • GET /v2/token/statusCek token masih berlaku atau tidak (header Authorization: Bearer {token})

Contoh membuat token

const API = 'https://api-mfikria.vercel.app';

const res = await fetch(`${API}/v2/token`, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ name: 'Budi' }) // opsional, maks 15 karakter
});
const { data } = await res.json();

// simpan token dan waktu kedaluwarsanya
localStorage.setItem('access_token', data.token);
localStorage.setItem('access_token_exp', String(data.expiresAt));

Contoh respons

{
  "status": "success",
  "data": {
    "token": "mfa_Budi_5ad8f0c5c08c1f1700d10164_PgQgYB2EoLQBRSgcN3tECG",
    "id": "acc-1a2b3c4d5e6f",
    "name": "Budi",
    "totalDays": 10,
    "expiresAt": 1792400000000,
    "expiresInMs": 864000000
  }
}

Cara memakai token

Kirim token di header Authorization: Bearer. Kalau dibalas 401 dengan code: "TOKEN_EXPIRED", buat token baru.

const token = localStorage.getItem('access_token');

const res = await fetch('https://api-mfikria.vercel.app/v2/donghua/anichi/latest', {
  headers: { Authorization: `Bearer ${token}` }
});

if (res.status === 401) {
  // token kedaluwarsa atau tidak valid: buat token baru
}

Cek status token

/v2/token/status selalu membalas 200. Baca data.valid; kalau false, data.code berisi alasannya.

{
  "status": "success",
  "data": {
    "valid": true,
    "id": "acc-1a2b3c4d5e6f",
    "type": "session",
    "name": "Budi",
    "expiresAt": 1792400000000,
    "remainingMs": 863000000,
    "remainingDays": 10
  }
}

Batasan

Pembuatan token dibatasi 10 permintaan per menit per IP (lebih dari itu dibalas 429, lihat header Retry-After). Pakai ulang token yang sudah tersimpan sampai kedaluwarsa.

Kode error

  • 401 TOKEN_MISSINGHeader Authorization kosong
  • 401 TOKEN_INVALIDToken salah atau tidak dikenali
  • 401 TOKEN_EXPIREDLewat 10 hari, buat token baru
  • 401 TOKEN_REVOKEDToken dicabut admin
  • 429Terlalu banyak permintaan
  • 503Validasi token sementara tidak tersedia, coba lagi sebentar

Guest Token

Token untuk pengunjung tanpa login. Setiap token tercatat di Google Sheet (tab GuestTokens).

  • POST /mfikria/v1/guest-tokenBuat guest token. Tanpa body dan tanpa header
  • GET /mfikria/v1/guest-viewJumlah guest yang pernah masuk (view), di-cache 30 detik

Contoh respons

{
  "status": "success",
  "message": "Guest token berhasil dibuat.",
  "data": {
    "userId": "G001",
    "Access_Token": "...",
    "pukul": "1535",
    "tanggal": "091026"
  }
}

Cara memakai token

Kirim sebagai query pada endpoint yang butuh guest token: ?query={Access_Token}&tgl={tanggal}, dengan nilai dari respons di atas.

Batasan

Maksimal 10 token per IP per jam (lebih dari itu dibalas 429) dan token berlaku 24 jam secara default. Token yang salah atau kedaluwarsa dibalas 401.

Contoh Kode

Ambil guest token, lalu pakai untuk mengambil 5 repository milik dodokjr.

JavaScript vanilla (di browser)

const API = 'https://api-mfikria.vercel.app';

async function getRepos() {
  // 1. ambil guest token
  const tokenRes = await fetch(`${API}/mfikria/v1/guest-token`, { method: 'POST' });
  const { Access_Token, tanggal } = (await tokenRes.json()).data;

  // 2. pakai token di endpoint GitHub
  const params = new URLSearchParams({ per_page: 5, query: Access_Token, tgl: tanggal });
  const res = await fetch(`${API}/v2/github/dodokjr/repos?${params}`);
  console.log(await res.json());
}

getRepos().catch(console.error);

      ))}
    </ul>
  );
}

Go (hanya library standar)

package main

import (
	"encoding/json"
	"fmt"
	"log"
	"net/http"
	"net/url"
)

const api = "https://api-mfikria.vercel.app"

func main() {
	// 1. ambil guest token
	res, err := http.Post(api+"/mfikria/v1/guest-token", "application/json", nil)
	if err != nil {
		log.Fatal(err)
	}
	defer res.Body.Close()

	var tok struct {
		Data struct {
			AccessToken string `json:"Access_Token"`
			Tanggal     string `json:"tanggal"`
		} `json:"data"`
	}
	if err := json.NewDecoder(res.Body).Decode(&tok); err != nil {
		log.Fatal(err)
	}

	// 2. pakai token di endpoint GitHub
	q := url.Values{}
	q.Set("per_page", "5")
	q.Set("query", tok.Data.AccessToken)
	q.Set("tgl", tok.Data.Tanggal)

	res2, err := http.Get(api + "/v2/github/dodokjr/repos?" + q.Encode())
	if err != nil {
		log.Fatal(err)
	}
	defer res2.Body.Close()

	var repos []struct {
		Name string `json:"name"`
	}
	if err := json.NewDecoder(res2.Body).Decode(&repos); err != nil {
		log.Fatal(err)
	}
	for _, r := range repos {
		fmt.Println(r.Name)
	}
}

Java 11 atau lebih baru (java.net.http bawaan, tanpa library tambahan)

import java.net.URI;
import java.net.URLEncoder;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.nio.charset.StandardCharsets;
import java.util.regex.Matcher;
import java.util.regex.Pattern;

public class Main {
    static final String API = "https://api-mfikria.vercel.app";

    // Ambil nilai string dari JSON sederhana (tanpa library JSON)
    static String find(String json, String key) {
        Matcher m = Pattern.compile("\"" + key + "\"\\s*:\\s*\"([^\"]*)\"").matcher(json);
        if (!m.find()) throw new IllegalStateException("Field tidak ditemukan: " + key);
        return m.group(1);
    }

    public static void main(String[] args) throws Exception {
        HttpClient client = HttpClient.newHttpClient();

        // 1. ambil guest token
        HttpRequest tokenReq = HttpRequest.newBuilder()
                .uri(URI.create(API + "/mfikria/v1/guest-token"))
                .POST(HttpRequest.BodyPublishers.noBody())
                .build();
        String tokenBody = client.send(tokenReq, HttpResponse.BodyHandlers.ofString()).body();
        String token = find(tokenBody, "Access_Token");
        String tanggal = find(tokenBody, "tanggal");

        // 2. pakai token di endpoint GitHub
        String url = API + "/v2/github/dodokjr/repos?per_page=5"
                + "&query=" + URLEncoder.encode(token, StandardCharsets.UTF_8)
                + "&tgl=" + URLEncoder.encode(tanggal, StandardCharsets.UTF_8);

        HttpRequest reposReq = HttpRequest.newBuilder().uri(URI.create(url)).GET().build();
        HttpResponse<String> res = client.send(reposReq, HttpResponse.BodyHandlers.ofString());
        if (res.statusCode() != 200) {
            throw new RuntimeException("HTTP " + res.statusCode());
        }
        System.out.println(res.body());
    }
}

GitHub

Ganti {nama} dengan username GitHub dan {repo} dengan nama repository. Semua endpoint butuh guest token (?query=&tgl=) dan dibatasi 60 request per menit per IP.

  • GET /v2/github/{nama}Profil pengguna
  • GET /v2/github/{nama}/reposDaftar repository
  • GET /v2/github/{nama}/repos/{repo}Detail satu repository
  • GET /v2/github/{nama}/repos/{repo}/eventsAktivitas repository
  • GET /v2/github/{nama}/repos/{repo}/languagesBahasa pemrograman yang dipakai
  • GET /v2/github/l/limitSisa kuota GitHub API (limit, remaining, reset)

Parameter opsional

Untuk /repos dan /events: per_page (1–100) dan page (1–1000). Contoh: /v2/github/dodokjr/repos?per_page=5&page=1&query=...&tgl=...

Kode error

  • 400Username atau nama repo tidak valid
  • 401Guest token tidak ada atau tidak valid
  • 404User atau repository tidak ditemukan
  • 429Batas request tercapai (server atau GitHub)
  • 502Gagal mengambil data dari GitHub

Respons di-cache sekitar 60 detik, jadi data bisa terlambat sedikit dari GitHub.

Video

Semua endpoint butuh guest token (?query=&tgl=). {token} adalah videoToken (10 karakter) dari daftar video.

  • GET /mfikria/v1/videosDaftar video beserta views, tanggal upload, dan info share
  • GET /mfikria/v1/video/{token}Stream video (mendukung Range), pakai sebagai src elemen <video>
  • GET /mfikria/v1/video-info/{token}Info satu video: judul, ukuran, views, tanggal upload, share
  • POST /mfikria/v1/video-view/{token}Catat 1 view. Panggil sekali setelah video diputar beberapa detik

Share & Embed

{id} adalah shareId dari objek share pada daftar video (sama dengan videoToken). Endpoint ini publik, tanpa guest token, kecuali /share-info.

  • GET /mfikria/v1/share/{id}Link untuk dibagikan. Langsung diarahkan ke halaman nonton di situs
  • GET /mfikria/v1/embed/{id}Player polos untuk <iframe>
  • GET /mfikria/v1/share-info/{id}Link share, kode iframe, dan link media sosial satu video (butuh guest token)
  • GET /mfikria/v1/s/{id}/streamStream video bertanda tangan (?e=&s=), dipakai halaman embed
  • POST /mfikria/v1/s/{id}/viewCatat view dari halaman embed (?e=&s=)

Contoh embed

<iframe src="https://api-mfikria.vercel.app/mfikria/v1/embed/k4n8lSIppy" width="640" height="360" frameborder="0" allow="fullscreen; autoplay" allowfullscreen loading="lazy" title="Judul video"></iframe>

Bot media sosial (WhatsApp, Facebook, Telegram, dan lain-lain) tetap mendapat halaman dengan meta Open Graph supaya preview link muncul. Link stream bertanda tangan berlaku 6 jam.

Akun

Endpoint akun memakai header Authorization: Bearer {token akses} (token akses user atau admin). Body dikirim sebagai JSON.

  • POST /mfikria/v1/registerDaftar akun. Body: username, password, role (opsional), photoId (opsional)
  • POST /mfikria/v1/loginMasuk. Body: username, password
  • POST /mfikria/v1/logoutKeluar. Body: username, encryptedQueryToken
  • GET /mfikria/v1/photosDaftar foto di folder Google Drive
  • GET /mfikria/v1/photoProfile/{token}Foto profil dari token terenkripsi
  • GET /mfikria/v1/assets/photo/{photoId}?q={token}Foto profil dengan photoId dan token
  • GET /mfikria/v1/assets/session-photo/{photoId}?query={encryptedQueryToken}Validasi sesi, atau ambil foto. Dengan Accept: application/json hanya data verifikasi

Aturan

  • Username maksimal 50 karakter, password 6–128 karakter.
  • Akun admin hanya bisa dibuat dengan token akses admin.
  • Satu akun hanya bisa aktif di satu sesi. Login saat akun masih online dibalas 403.
  • Password disimpan sebagai hash (scrypt), bukan teks asli.

World

Data ekonomi semua negara dari World Bank, digabung dalam satu respons. Endpoint ini memakai Access Token yang sama dengan Otaku & Anichi, dikirim lewat header Authorization: Bearer {token}. Token berlaku 10 hari dan dibuat lewat halaman Access Token.

Buat Access Token

Berbeda dengan endpoint lain, respons bagian Ekonomi dan Mata Uang (World, Country, Currency) memakai "success": true atau "success": false, bukan "status".

Endpoint

  • GET /v2/worldSemua negara beserta indikator ekonomi, dengan filter, urutan kaya/miskin, dan paginasi
  • GET /v2/world/{kode}Satu negara berdasarkan kode (hasilnya sama dengan /v2/country/{kode})

Setiap negara berisi nama, region, level pendapatan, ibu kota, koordinat, dan indikator: gdp (PDB, US$), gdpPerCapita (PDB per kapita, US$), gdpGrowth (pertumbuhan PDB, %), inflation (inflasi, %), unemployment (pengangguran, %), dan population (populasi). Tiap indikator berisi value dan year, atau null bila datanya tidak ada.

Parameter /v2/world

  • qCari berdasarkan nama negara, contoh ?q=indo
  • regionFilter region, contoh ?region=East Asia
  • incomeLevelFilter level pendapatan, contoh ?incomeLevel=High
  • sortrichest (paling kaya) atau poorest (paling miskin). Hasil diberi nomor rank
  • byUkuran kaya untuk sort: gdpPerCapita (default) atau gdp (total PDB). Negara tanpa data dibuang dari urutan
  • pageNomor halaman, bilangan bulat ≥ 1 (default 1)
  • limitData per halaman, 1–250 (default 20). Pakai ?limit=250 untuk mengambil semua negara sekaligus

Contoh

const API = 'https://api-mfikria.vercel.app';
const token = localStorage.getItem('access_token');
const headers = { Authorization: `Bearer ${token}` };

// 10 negara terkaya (per kapita), halaman 1
const rich = await fetch(`${API}/v2/world?sort=richest&limit=10`, { headers });
console.log(await rich.json());

// 5 negara termiskin berdasarkan total PDB, halaman 2
const poor = await fetch(`${API}/v2/world?sort=poorest&by=gdp&page=2&limit=5`, { headers });

// Negara Eropa, 3 terkaya
const eu = await fetch(`${API}/v2/world?region=Europe&sort=richest&limit=3`, { headers });

if (rich.status === 401) {
  // token kedaluwarsa atau tidak valid: buat token baru
}

  • Halaman yang melewati totalPages membalas data kosong dengan pagination tetap benar.

Currency

Kurs dan daftar mata uang dunia dari CurrencyFreaks. Memakai Access Token yang sama dengan bagian World dan Otaku & Anichi (header Authorization: Bearer {token}). Kunci API CurrencyFreaks disimpan di server, jadi client cukup memakai access token Anda.

  • GET /v2/currenciesSemua mata uang dunia (fiat, logam, dan kripto) beserta kurs terhadap USD. Parameter: q (kode, nama mata uang, atau negara) dan limit
  • GET /v2/currencySemua kurs terbaru. Parameter opsional: symbols, contoh ?symbols=IDR,EUR,JPY
  • GET /v2/currency/{kode}Kurs satu mata uang, contoh /v2/currency/IDR (1 USD = berapa IDR)
  • GET /v2/currency/convertKonversi antar mata uang. Parameter: from (default USD), to (wajib), amount (default 1)

Contoh

const API = 'https://api-mfikria.vercel.app';
const token = localStorage.getItem('access_token');
const headers = { Authorization: `Bearer ${token}` };

// Daftar mata uang, cari berdasarkan nama
await fetch(`${API}/v2/currencies?q=rupiah`, { headers });

// Kurs beberapa mata uang sekaligus
await fetch(`${API}/v2/currency?symbols=IDR,EUR,JPY`, { headers });

// Kurs satu mata uang
await fetch(`${API}/v2/currency/IDR`, { headers });

// Konversi 100 USD ke IDR
const res = await fetch(`${API}/v2/currency/convert?from=USD&to=IDR&amount=100`, { headers });
const { data } = await res.json();
console.log(data.result);
