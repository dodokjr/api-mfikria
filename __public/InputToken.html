Access Token

Token untuk memanggil endpoint /v2/anime dan /v2/donghua. Token berlaku 10 hari (sesuai pengaturan server). Isi nama bebas (opsional) untuk membuat token. Setelah kedaluwarsa, buat token baru di halaman ini.

Cara mendapatkan Access Token

  1. Isi kolom Nama di bawah dengan teks bebas, maksimal 15 karakter. Kosongkan untuk memakai string acak 15 karakter.
  2. Klik Buat Access Token. Server membuat token dari nama dan teks acak, lalu mencatatnya di Google Sheet.
  3. Salin token yang muncul (berlaku 10 hari) dan kirim di header Authorization: Bearer.

Admin membuat token tanpa batas waktu lewat halaman admin.html dengan Admin Key dan nama (misalnya Admin).

Cara memakai token

        
Kirim token di header Authorization: Bearer. Kalau dibalas 401 dengan code: "TOKEN_EXPIRED", buat token baru.

        

          
const API = 'https://api-mfikria.vercel.app';
const token = localStorage.getItem('access_token');

const res = await fetch(`${API}/v2/donghua/anichi/latest`, {
  headers: { Authorization: `Bearer ${token}` }
});

if (res.status === 401) {
  // token kedaluwarsa atau tidak valid: buat token baru di halaman ini
}
